# Charte graphique MyBank

## Couleurs
| Rôle | Variable CSS | Valeur |
|---|---|---|
| Primaire (navbar, sidebar) | `--color-primary` | `#156064` |
| Action (boutons, liens actifs) | `--color-accent` | `#00C49A` |
| Accent (badges, graphiques) | `--color-highlight` | `#F8E16C` |
| Fond général | `--color-bg` | `#f9f9f7` |
| Texte courant | `--color-text` | `#333333` |

## Typographie
- Police : **Montserrat** (Google Fonts)
- Variable CSS : `--font-main`
- Weights : 400 / 500 / 600 / 700

## Responsive
| Breakpoint | Largeur |
|---|---|
| Mobile | 375px |
| Tablette | 768px |
| Desktop | 1280px |

## Règles de style
- Toujours utiliser les variables de `front/src/styles/theme.css` — jamais de couleurs en dur
- Police Montserrat importée dans `front/index.html`
